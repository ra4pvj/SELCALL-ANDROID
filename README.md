# HF Selcall для Android

Android-версия [HF Selcall](https://github.com/ra4pvj/SELCALL): приём и передача КВ-селкола **CCIR 493-4**, совместимого с трансиверами CODAN (а также Barrett, Q-MAC, Vertex). Кодек — перенос `python/selcall.py` / `SelcallCore` на Java, алгоритм тот же: АПЧ 1000–2600 Гц, USB/LSB, проверка копий DX/RX.

## Скачать

Готовый APK — в [Releases](https://github.com/ra4pvj/selcall-android/releases): `HFSelcall-Android.apk` (Android 8.0 и новее). Постоянные релизы `vX.Y.Z` и пре-релиз `latest` (последняя сборка из `main`).

Установка: скачать APK на телефон, открыть, разрешить установку из этого источника.

## Что умеет

- **Selcall** (4- или 6-значные ID) и **Message call** (текст до 64 символов, кириллица транслитерируется);
- **приём в фоне** (foreground-сервис, при выключенном экране), индикатор уровня, лампы RX/TX, журнал с временем; нажатие на строку журнала подставляет отправителя в «Кому»;
- **звонок** при вызове на свой ID: двухтональный, трель, гудки или «Калинка»; вибрация, уведомление поверх экрана блокировки, баннер «Ответить / Сбросить»;
- **ответ в эфир** через 1 с после вызова (сигнал выбирается отдельно);
- **PTT / CAT** через USB-COM (CP210x/Digirig, FTDI, CH340, PL2303, CDC-ACM): RTS / DTR / RTS+DTR (с инверсией), ICOM CI-V, YAESU, YAESU-OLD, KENWOOD, ELECRAFT; задержка PTT и хвост; VOX — без кабеля;
- выбор входа/выхода (USB-аудио, гарнитура, встроенные), источник входа без АРУ;
- пауза приёма на время передачи; распознавание собственного эха;
- **WAV**: декодировать запись, сохранить вызов в файл; самопроверка кодека в меню.

## Подключение

Удобнее всего — USB-аудиоинтерфейс трансивера (Digirig Mobile, SignaLink USB, встроенный USB-кодек IC-7300/IC-705 и т.п.) через OTG-переходник: Android сам переключает звук на USB-карту, или выберите её в ⚙ → «Вход»/«Выход». Digirig даёт и звук, и COM-порт для PTT (RTS).

Для надёжного фонового приёма отключите для приложения оптимизацию батареи (Настройки Android → Приложения → HF Selcall → Батарея → «Без ограничений»).

Не перенесены пока из настольной версии: самоконтроль на отдельные устройства, «прослушивание эфира» после вызова, внешнее устройство (реле) на отдельном COM-порту.

CAT-команды составлены по документации и на трансиверах не проверялись — «Тест PTT» лучше делать на эквивалент нагрузки.

## Сборка

```bash
./gradlew testReleaseUnitTest   # самопроверка кодека (в т.ч. на реальной записи CODAN)
./gradlew assembleRelease       # app/build/outputs/apk/release/app-release.apk
```

Нужны JDK 17 и Android SDK (API 35). Сборку и релиз делает GitHub Actions (`.github/workflows/build.yml`); чтобы выпустить версию, поменяйте номер в `VERSION` и отправьте в `main`.

APK подписывается ключом `app/release.jks` из репозитория (пароль `hfselcall`), чтобы обновления ставились поверх. Чтобы подписывать своим закрытым ключом, задайте секреты `SIGNING_KEYSTORE_B64`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD` (после смены ключа приложение придётся переустановить).

## Состав

| Путь | Что это |
|---|---|
| `app/src/main/java/ru/ra4pvj/selcall/core` | кодек (чистая Java): модуляция, кадр CCIR 493-4, декодер, АПЧ, потоковый приёмник, WAV, сигналы звонка |
| `app/src/main/java/ru/ra4pvj/selcall` | приложение: экран, настройки, сервис приёма/передачи, USB PTT |
| `app/src/test` | unit-тест кодека + эталонная запись `SELCALL_from_1111_to_1234.wav` |

Протокол и неподтверждённые места (раскладка текста Message call) — см. README [ra4pvj/SELCALL](https://github.com/ra4pvj/SELCALL#протокол-кратко).
